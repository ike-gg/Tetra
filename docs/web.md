# Tetra web

Website and panel (`apps/web`). Paths in this document are relative to `apps/web`.

**Stack:** TanStack Start (Vite), TanStack Router (file-based routes), React 19, TanStack Query, Tailwind CSS v4.

## Rendering

- **SPA mode** with selected pages prerendered. There is no server at runtime: the build output is static files.
- **Homepage** (`/`) and other public pages: prerendered to HTML at build time. Add their paths to `staticPages` in `vite.config.ts`.
- **Panel** (`/panel/*`): client-only (`ssr: false` on the route). Served by the SPA shell `_shell.html`; the host must rewrite unknown paths to it.
- The shell is rendered with `spa.maskPath: "/panel"` so it doesn't collide with the prerendered `/`.
- In `vite dev` every route renders on the client, including `/`.

## Structure

| Path | Contents |
|---|---|
| `src/routes/` | File-based routes. `__root.tsx` = document, head, `QueryClientProvider`. |
| `src/router.tsx` | Router + `QueryClient` (passed as router context). |
| `src/routeTree.gen.ts` | Generated by the router plugin on dev/build. Not edited by hand, ignored by Biome. |
| `src/styles/app.css` | Tailwind entry: fonts, theme tokens, base styles. |
| `src/assets/fonts/` | Self-hosted Geist woff2 files (copied from the `geist` npm package, OFL). |
| `src/components/emote-background.tsx` | Homepage background, see [web/background.md](web/background.md). |
| `scripts/build-emote-atlas.ts` | Generates the background's emote atlas into `public/`. |

## Styling

Tailwind v4, configured in CSS (`@theme` in `src/styles/app.css`); dark only.

- **Fonts:** `font-sans` = Geist (default for everything), `font-serif` = Geist Serif (display serif with a single 400 weight, use only as an accent for headings), `font-mono` = Geist Mono (ASCII-art accents, also used by the homepage background glyphs).
- **Colors** (OKLCH): `brand-50…950` built around `#f64f02` (`brand-500`); `neutral-*` is Tailwind's scale with a faint tint of the brand hue. Prefer the semantic tokens: `background`, `surface`, `foreground`, `muted`, `border`, `primary`, `primary-hover`, `primary-foreground`. Text on `primary` is dark (`primary-foreground`), white on the orange fails contrast.

## Talking to the API

Not wired yet. The API lives in core (`/api`, see [core.md](core.md#api)) and authenticates with the `tetra-session` cookie (`sameSite: lax`), so web and API must be on the same site; any port on localhost works in development.

## Scripts

Run inside `apps/web`, or from the root with `bun --filter @tetra/web <script>`.

- `dev` – `vite dev` on port 3000
- `build` – static build to `dist/client`
- `preview` – serve the build
- `typecheck` – `tsc --noEmit`
- `build:emote-atlas` – regenerate the homepage background atlas (manual, output is committed)
